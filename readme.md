# IITB Canteen & Mess Hygiene Portal

A modern web-based hygiene and food review portal designed for the IIT Bombay campus community.  
This platform allows students to submit feedback about hostel messes, night canteens, and institute eateries while helping improve hygiene standards and food quality across campus.

# ✨ Features

- 🏫 Review hostel messes, night canteens, and institute eateries
- ⭐ Star rating system for:
  - Overall Experience
  - Food Quality
  - Cleanliness & Hygiene
- 🧾 Detailed written feedback section
- 📷 Optional image upload support
- 📅 Visit date selection
- 🍽 Meal-time categorization
- 🚚 Service type selection (Dine In / Takeaway / Delivery)
- ⚠ Hygiene complaint checklist
- 📱 Fully responsive UI for mobile and desktop
- 🔄 Real-time loading of recent reviews
- ✅ IIT Bombay email validation (`@iitb.ac.in`)
- ☁ Google Apps Script backend integration
- 🎨 Modern professional UI with animations
